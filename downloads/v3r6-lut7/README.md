# Thai-Menu v3r6-lut7 Recovery

**Canon EOS 600D / firmware 1.0.2 — UPDATE สำหรับกู้กลับจาก lut6 ที่ค้างตั้งแต่เปิดสวิตช์**

[ดาวน์โหลด UPDATE](https://raw.githubusercontent.com/itsamachom/EOS_ROM_MLV_Modify/v3r6-lut7/downloads/v3r6-lut7/camera/600D-102-Thai-Menu-v3r6-lut7-UPDATE.zip) · [วิธีติดตั้ง/ขอบเขต](../../PHOTO_UI_V3R6-LUT7.md) · [SHA256](SHA256SUMS)

รุ่นนี้ย้อน core ไปฐาน lut5 ในส่วนปุ่ม/วาด/ฟิลเตอร์ และ **ปิดตัวแปลงฟิล์มทั้งอัตโนมัติและการกดเมนู** เพื่อให้ทดสอบการกลับมาใช้งานกล้องก่อน ไม่เปิดฟีเจอร์ Live View LUT/JPEG อัตโนมัติ/ตัวดูผล lut6

สำรองการ์ดบน PC ก่อน แล้วคัดลอก **autoexec.bin และ ML/ ทั้งชุด** จาก ZIP ลงรากการ์ดและทับชุดเดิม ไม่เรียก Firmware Update ไม่ลบ autoexec.bin บนการ์ด bootable โดยไม่มีไฟล์ใหม่แทน ภาพ RAW/DCIM เดิมไม่ถูกลบ

**ผ่าน ARM build และ host tests แต่ยังไม่มีผลบูตบนกล้องจริง ไม่รับรองว่าแก้ต้นเหตุได้แน่นอน** หากยังค้างให้หยุดทดลองการ์ดชุดนี้และกู้โดยถอดแบต/เอาการ์ดออกตามวิธีที่ใช้ได้ก่อนหน้า
