LUT JPEG experiment
===================
600D.102 only. Select Portra 400, Ektar 100 or Tri-X 400 and convert the
latest RAW after shooting. Real RAW-to-LUT-to-JPEG processing, 720x480.
Set Canon RAW or RAW+JPEG first. Conversion is manual in this first prototype.
Writes a new JPEG and screen print under ML/LUTOUT; never replaces originals.
Based on M-Film GPL-2.0-only processing, see upstream/PROVENANCE.json.
